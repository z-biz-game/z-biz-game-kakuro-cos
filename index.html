    你会用到的六条规则

    1. 组合清单：L 格和 S 的组合一只手数得过来，交叉那格的候选就是两份清单的交集。
    2. 唯一组合：某条 run 只剩一种组合，这套数字就把两条 run 的格子都框住了。
    3. 必含之数：剩下的每种组合都含 7，而这条 run 只有一格放得下 7——那就是 7。
    4. 占位排他：把数字逐个摆回空格试，摆不下的那个候选就可以划掉。
    5. 进差法：把几行看成一片，横着的和减掉竖着的和，差额就落在伸出去的那几格上。
    6. 只剩一个：一横一竖两份清单夹到只剩一个数字，直接写下。

    六条都不含猜测：它们写下的每一步，对盘面的每一个解都成立——所以铅笔推得完就等价于唯一解，出货时再由第二套穷举实现独立数一遍。
